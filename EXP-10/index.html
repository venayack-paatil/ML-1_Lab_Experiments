About This Project

This application uses a Support Vector Machine with an RBF kernel to classify dry beans into one of seven varieties based on 16 numerical measurements.

This is an educational machine learning demonstration. Predictions depend on the quality and range of the supplied measurements.

Built with Python, Flask, HTML, CSS and Scikit-learn
